# Mutual Fund Data Analysis & Top 30 Fund Ranking

## Project Overview
This project focuses on analyzing a comprehensive mutual fund dataset containing 814 records and identifying the Top 30 mutual funds based on a calculated scoring methodology.

After performing data cleaning, preprocessing, and exploratory data analysis using Python, the Top 30 selected mutual funds were exported and used to develop an interactive Power BI dashboard.

The dashboard provides insights into fund performance, returns, expense ratios, categories, AMCs, and risk levels.

## Dataset Information
- Total Records: 814
- Total Columns: 20
- Dataset Format: CSV

## Tools & Technologies
- Python
- Pandas
- NumPy
- Microsoft Excel
- Microsoft Power BI

## Project Workflow
1. Imported and explored the mutual fund dataset.
2. Performed data cleaning and missing value analysis.
3. Conducted Exploratory Data Analysis (EDA).
4. Calculated a final score for mutual fund ranking.
5. Identified and selected the Top 30 mutual funds.
6. Exported the selected Top 30 funds for further analysis.
7. Developed an interactive Power BI dashboard using the Top 30 selected funds.

## Top 30 Fund Selection
The Top 30 mutual funds were selected using a scoring methodology considering:
- 3-Year Returns – Higher returns preferred.
- Expense Ratio – Lower expenses preferred.
- Fund Age – Considered in the scoring process.
- 1-Year Returns – Positive returns preferred.

## Power BI Dashboard Features
The interactive dashboard was created using the selected Top 30 mutual funds.

- Fund Type Analysis
- Category and Sub-category Analysis
- AMC-wise Comparison
- Risk Level Analysis
- Rating Analysis
- Top 30 Mutual Fund Performance
- Interactive Slicers and Filters

## Project Outcome
Successfully analyzed 814 mutual funds using Python and identified the Top 30 funds through a scoring approach. The selected funds were then visualized using Power BI to create an interactive dashboard for fund comparison and performance analysis.

## Conclusion
This project demonstrates an end-to-end data analysis workflow, from raw dataset cleaning and analysis using Python to fund ranking and interactive dashboard development using Power BI.
